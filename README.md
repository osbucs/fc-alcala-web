# FC Alcalá - Sitio Oficial

Este es el sitio web oficial de **Alcalá Deportivo Rs.**, un equipo de fútbol profesional. El sitio está diseñado con una estética moderna "Dark Mode", inspirado en plataformas deportivas de alto nivel.

## Características

- **Diseño Responsivo**: Optimizado para dispositivos móviles, tablets y escritorio.
- **Secciones Detalladas**: Información sobre categorías, plantel, inscripciones y galería.
- **Interacción Directa**: Integración con WhatsApp para consultas rápidas.
- **Estética Premium**: Uso de animaciones suaves, gradientes y tipografía moderna.

## Tecnologías Utilizadas

- HTML5 (Estructura Semántica)
- CSS3 (Variables, Grid, Flexbox, Animaciones)
- JavaScript (Interacciones, Navegación móvil, Lightbox)

## Créditos

Desarrollado para Real Sociedad Deportiva Alcala.
